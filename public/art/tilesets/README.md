## Forest Tilemap

- Arquivo: `forest-tilemap-cc0.png`
- Autores: Vomdrache / equipe Rising Spire
- Fonte: https://opengameart.org/content/forest-tilemap
- Licença: CC0
- Uso: camada complementar de grama, margem, água e caminho para floresta, floresta tropical, outono, manguezal, costa, lago, planície e vila.

Os recursos são mantidos em resolução original e renderizados com nearest-neighbor no grid de 32 px. Eles não substituem o atlas protegido de Slime, Golem, Morcego ou chefes.

O repositório `bastiao_do_vale` foi consultado como referência de composição amazônica (camadas de floresta, rios, açaí, helicônias e fauna), mas nenhum código ou asset foi copiado para este projeto.
