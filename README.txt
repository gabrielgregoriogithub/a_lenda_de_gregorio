A LENDA DE GREGÓRIO — A RELÍQUIA | EDIÇÃO OFFLINE RECONSTRUÍDA

IMPORTANTE: Este pacote NÃO é o código-fonte exportado do projeto original
publicado em vale-da-lua-greg.gabrielgregorio10.chatgpt.site.
A publicação existe na biblioteca do usuário, mas a exportação do seu código
não estava disponível. Esta é uma recriação independente e jogável baseada
nas instruções e informações visíveis daquela publicação.

COMO JOGAR
1. Extraia todo o ZIP para uma pasta.
2. Clique duas vezes no arquivo index.html e abra em Chrome, Edge ou Firefox.
3. Clique em "Começar aventura".

CONTROLES
WASD ou setas: mover
J ou Espaço: atacar com espada / cortar arbustos
E: interagir
Shift: esquivar
Q: usar poção
P: pausar

OBJETIVOS
1. Converse com Iris, abra o baú e obtenha a chave.
2. Siga ao leste para o portão, atravesse o bosque e entre no templo.
3. Ative os dois selos, derrote o guardião e alcance o altar.

ARQUIVOS
index.html — estrutura do jogo
style.css — estilo visual
game.js — lógica completa em JavaScript, sem bibliotecas externas
README.txt — estas instruções

Não precisa instalar programas, não precisa de servidor, internet ou assets externos.
