# Efeitos de combate

O efeito `sword-swing.ogg` (golpe da espada no ar) é o `blade_01.ogg` da pasta local `80-CC0-RPG-SFX_0`, baseada no pacote **80 CC0 RPG SFX**. O tom varia levemente a cada golpe.

Os gritos de esforço, o acerto, o acerto crítico, o dano no herói e a esquiva são sintetizados em tempo real via Web Audio em `lib/adventure.ts`.

As referências de catálogo usadas para a seleção incluem o [assets-sfx-combat](https://github.com/GeorgeQLe/assets-sfx-combat) e o [open-game-sfx-index](https://github.com/Mcamento8/open-game-sfx-index), que catalogam efeitos CC0 de combate/RPG.
